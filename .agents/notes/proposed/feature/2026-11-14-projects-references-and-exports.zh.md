# Agent Note: 项目与导出引用素材库，而不是拥有它

Status: proposed

[English](2026-11-14-projects-references-and-exports.md) | 中文

## Problem

旧工作台允许项目引用共享数据集和素材，显示一次编辑会影响哪些项目，并把导出作为独立任务运行，带逐项结果。新 schema 的诱惑是给每个项目一份图像副本，或者把导出当成新的素材库素材。两者都会破坏单一原件规则：同一张 light 帧会有多个 id，编辑会分叉，删除项目可能删掉另一个项目仍在使用的数据。

## Proposal

项目是素材库条目上的命名工作区。它按 id 引用素材和数据集，从不复制它们。导出是把文件写到素材库之外并返回回执的任务；只有用户显式登记结果时，它才创建素材库素材。

### 项目与引用

项目有 id、名称、可选备注、状态、修订号和有序引用。引用指向素材或数据集，二者取一，并且在每个项目和目标上唯一。引用顺序是项目的展示顺序；它不改变数据集成员顺序。

一个数据集可以被多个项目引用。它的成员、顺序和校准绑定是共享的：在一个项目里的编辑会在引用它的每个项目里可见，数据集详情会在保存前列出受影响的项目。需要不同校准或不同成员顺序的项目需要不同的数据集。

素材可以是 `shared`，或者由一个项目拥有。共享素材可以被任何项目引用。项目拥有的素材在显式改为共享或重新分配之前，只能被所属项目引用。所有权是可见性规则，不是副本；素材 id 和文件都不变。

移除引用不删除目标。删除项目需要为它拥有的素材选择处置方式：移到另一个项目、改为共享，或作为一个条目移入回收站。预检列出每个拥有的素材和每个外部引用；不会隐式删除任何素材。

### 导出

导出任务记录调用方的 `request_id`、有序选择（素材或数据集）、输出配置、目标位置、冲突策略，以及 `queued`、`running`、`completed`、`completed_with_errors`、`failed` 或 `cancelled` 状态。任务开始时选择被冻结：之后的素材库编辑不会改变任务读取的内容。

任务为每个选中条目写一个文件，或者在配置要求时每个数据集写一个文件。每项记录来源素材 id、输出路径、字节、哈希和状态。失败项不会丢弃成功项；任务以 `completed_with_errors` 结束，回执同时列出两者。

默认冲突策略是失败而不是覆盖。覆盖需要显式标志和将被替换文件的预览。导出永远不写进托管素材库；它写到用户选择的目标位置，回执记录该路径。

导出的文件默认不是素材库素材。如果用户要求登记它，正常导入路径会分配新素材 id，并把导出回执记录为来源。重新导出同一选择会创建新任务和新文件；它不会悄悄替换之前的回执。

### 结果

用户想留在素材库里的操作结果会登记为 `intermediate` 或 `final` 角色的素材，并带有指向操作回执和输入素材 id 的来源链接。只下载的结果是导出，不是素材。两条路径共享回执格式，但不共享身份规则：结果素材有稳定 id；导出文件只有任务条目。

### 删除与影响

清理被引用的素材或数据集会被项目引用阻塞，直到引用被移除或项目被删除。清理预览列出项目。删除项目不删除共享目标，它拥有的素材按预检中选择的处置方式处理。

## Alternatives considered

**把素材复制进每个项目。** 否决：同一帧会有多个 id，编辑和校准会分叉，存储会随着每次引用增长。引用加数据集共享才能保持每个素材一个原件。

**删除项目时一并删除它的素材。** 否决：项目可能拥有另一个项目即将引用的图像，而且没有回收站流程的删除不可逆。预检必须强制显式处置。

**把每次导出都当成素材库素材。** 否决：导出是用户选择格式和目标位置的派生副本；自动登记会污染素材库并制造重复身份。

**把导出写进托管素材库目录。** 否决：素材库拥有自己的副本并跟踪哈希。写进那棵树会绕过导入，让账本出错。

**允许项目本地覆盖数据集顺序或校准。** 否决：数据集是顺序和校准的单位；本地覆盖会让同一数据集在不同项目里含义不同。应该创建单独的数据集。

## Acceptance criteria

- 项目按 id 引用素材和数据集，从不复制它们的文件。
- 被多个项目引用的数据集在保存共享编辑前报告受影响的项目。
- 移除引用不删除目标。
- 删除项目需要为拥有的素材显式选择处置方式；没有素材被隐式删除。
- 导出在开始时冻结选择，并报告逐项状态。
- 导出项失败不会丢弃成功项；任务以 `completed_with_errors` 结束。
- 覆盖已有文件需要显式标志和预览。
- 导出不写进托管素材库；登记结果走正常导入。

## Risks

- 项目所有权增加了一条每个素材库查询都必须应用的可见性规则；漏掉过滤会泄漏项目专属素材。
- 共享编辑可能让另一个项目意外。受影响项目列表必须出现在保存之前，而不只是审计日志里。
- 导出回执可能很大；逐项结果需要分页和稳定任务 id。
- 用户可能期望导出出现在素材库里。UI 必须说明导出是文件，并把登记作为单独操作提供。
