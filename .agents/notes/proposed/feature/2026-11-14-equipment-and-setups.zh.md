# Agent Note: 设备是快照，不是实时查询

Status: proposed

[English](2026-11-14-equipment-and-setups.md) | 中文

## Problem

旧素材库允许用户登记相机、望远镜、滤镜和赤道仪，把它们组合成设备组合，并把组合应用到导入的图像上。图像随后保留一份冻结的设备快照。冻结正是重点：编辑相机的像元尺寸或删除一个滤镜，不能改写早先图像是用什么拍的。新仓库还没有设备契约，而实时外键查询会悄悄改变历史、误报有效焦距，并让删除一个设备破坏旧数据集。

## Proposal

设备记录是可复用的定义。设备组合是定义的命名组合。素材保留两者的冻结快照，外加用于导航的可选 id。

### 定义

一个设备有 id、名称、种类、可选备注、`active` 或 `archived` 状态、修订号和种类专属规格：

- `camera`：像元尺寸（微米）、传感器宽高（像素）、像素阵列（`mono`、特定 Bayer 或 X-Trans 排列，或 `unknown`），以及可选位深。未指定阵列就是 `unknown`，永远不假定为 mono。
- `telescope`：原生焦距（毫米）、口径（毫米）和可选光学设计。附件属于设备组合，不烘进望远镜。
- `filter`：滤镜上印的标签、可选通道名称和可选带宽（纳米）。通道是自由文本；服务不会从标签猜波长或波段。
- `mount`：名称、型号和备注。没有控制通道，也没有驱动连接。

名称是标签，不是身份。重命名设备保留 id，不改变任何快照。归档会把设备从新选择中移除，但保留已有引用和快照。

### 设备组合

设备组合有 id、名称、可选成像相机、可选导星相机、可选望远镜、可选赤道仪、有序滤镜列表、有序光学附件列表、可选软件备注、修订号和状态。

光学附件有名称和正数倍率。组合的有效焦距是选中的望远镜原生焦距乘以选中的附件倍率。计算值连同输入一起展示；它不会作为独立可编辑数字存储。

每个成员必须是种类匹配的活跃设备。设备组合不隐式创建设备，从组合移除设备也不会重排或替换其余成员。

### 素材快照

当导入或显式应用把设备绑定到素材时，素材存储一个 JSON 快照，包含组合构成和每个设备的名称、种类与规格，以及选中的 id 和有效焦距输入。来自设备的元数据字段在 `value_sources` 中标记为 `equipment`；手动编辑会把来源替换为 `manual`。

之后对设备或组合的编辑、归档或删除都不会改写快照。素材详情仍然可以链接到当前定义，但展示的拍摄事实来自快照。当前定义缺失时显示为不可用，而不是显示为拍摄事实变了。

### 导入默认值

预检可以为一批文件建议一个组合及其设备。建议是默认值，不是前提：用户可以不带设备导入、带部分组合导入，或逐文件覆盖。优先级是手动、文件观测值、冻结的组合默认值、未知。设备默认值永远不会覆盖单帧记录的曝光、增益、偏移或实测温度。

### 删除与归档

删除设备或组合需要预检，报告引用它的素材、组合和校准关系，以及该影响的指纹。确认必须使用相同的选择和指纹；影响变化返回 `409`，并要求重新预览。

删除设备会把它从当前组合移除，同时保留其他成员的 id 和顺序；它不会选择替代品。删除组合只移除组合本身；它不删除设备、图像或原件。素材快照在任一删除后都保留。

## Alternatives considered

**把素材实时连接到设备行。** 否决：编辑相机会改变每张旧图像的含义，删除滤镜会破坏它们。快照是历史事实；行是当前定义。

**只把设备保留为自由文本元数据。** 否决：它失去复用、组合构成，以及在导入或校准时检查兼容性的能力。自由文本也无法可靠表达像元尺寸或附件倍率。

**要求每次导入都有设备组合。** 否决：很多用户导入单张文件时没有登记设备，组合是便利而不是门槛。未知设备是有效状态。

**级联删除设备及依赖素材。** 否决：删除相机不能删除用它拍的图像。预检展示影响并要求显式决定。

**在设备组合之外再加拍摄预设。** 首版否决：组合已经描述光学链路，再加一层预设会让同一批默认值出现两个事实来源。以后可以在不改变快照格式的前提下增加预设。

**删除设备时自动替换每个组合中的它。** 否决：替代品规格可能不同，会悄悄改变有效焦距和兼容性。组合显示缺失成员，让用户决定。

## Acceptance criteria

- 设备可以带修订检查地创建、编辑、归档和删除；归档把它从新选择中隐藏，不改变已有快照。
- 组合只接受种类匹配的活跃设备，保留成员顺序，并根据望远镜和附件倍率计算有效焦距。
- 应用组合会在素材上存快照，并把设备派生字段标记为 `value_sources=equipment`。
- 编辑或删除设备、组合不会改变任何素材快照。
- 导入可以在无设备、部分组合或逐文件覆盖下工作；手动值优先于设备默认值。
- 删除设备会把它从当前组合移除，不重排也不替换其他成员。
- 删除预检报告受影响的素材和组合，并拒绝过期确认。
- 没有服务暴露赤道仪控制、相机控制或硬件驱动。

## Risks

- 快照会复制数据，并可能与当前定义漂移；UI 必须标明哪些值是历史值、哪些是当前值。
- 滤镜标签是用户文本，所以两个相同滤镜可能有不同名称。匹配必须使用标签加可选通道，永远不猜波长。
- 删除设备可能影响很多组合；预检必须能分页展示大影响列表并保持可读。
- 用户可能期望编辑设备会更新旧图像。素材详情必须在困惑发生的地方解释冻结。
