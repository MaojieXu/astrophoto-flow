# Agent Note: 素材库是一个可查询的列表

Status: proposed

[English](2026-11-14-library-browsing-and-editing.md) | 中文

## Problem

旧工作台把素材和数据集放在同一个分页表格里，带全局筛选、简约/细节列、缩略图和行内元数据编辑。新仓库还没有素材库查询和编辑契约。把素材和数据集拆成两个页面会重复筛选、分页和校准状态逻辑；在浏览器里筛选对一百行还行，对采集档案就会失效。编辑时不检查修订号，会让两个打开的面板互相覆盖，而且都报告成功。

## Proposal

素材库是一个对素材摘要和数据集摘要的服务端查询，加上每行的详情表面。同一个查询支撑网页表格、CLI 和 MCP 工具。

### 一个列表

`GET /library/items` 返回一页混合行：独立图像是素材行，子帧组是数据集行。两者都带稳定 id、名称、缩略图引用、状态和修订号。数据集行聚合成员：成员数、累计曝光、统一或混合的校准状态，以及问题计数。行内不展开成员；详情视图才展开。

排序是显式且稳定的：名称、导入时间、拍摄时间或最后编辑，升序或降序。分页支持 10、20、50 和全部，总数由服务端计算。一页是快照，不是实时游标；响应携带轻量变更令牌，客户端可以刷新而不必整页重载。

### 列与筛选

简约列是名称、按用途的校准单元格、分类、相机、ISO 或增益、曝光和温度。细节列增加 binning、CFA、成像系统、滤镜、累计曝光、存储、可用性、状态和备注。数据集行显示聚合曝光和校准计数，而不是逐成员值。

筛选在服务端执行：名称全文搜索、校准状态、素材形态、帧用途、分类、相机、成像系统、滤镜、ISO 或增益模式、binning，以及曝光、累计曝光、温度、ISO、增益和偏移的数值范围。筛选选项端点返回当前素材库观察到的范围和不同值，滑块永远不会提供没有任何行能匹配的值。`unknown` 是一个筛选值，不是空字符串。

### 编辑

行内编辑覆盖名称、校准状态和证据、素材形态、帧用途、ISO 或增益、偏移、相机、成像系统、滤镜、曝光、累计曝光、温度、binning、CFA、状态和备注。数据集只能编辑名称、状态和备注；成员、顺序和校准绑定在数据集详情里。

每次编辑都携带用户看到的修订号。过期修订返回 `409 REVISION_CONFLICT` 和当前修订；客户端重新加载该行，而不是盲目重试。成功的手动编辑写入 `value_sources[field] = manual`，这样之后的导入或设备变更不会悄悄替换用户决定。批量元数据和设备应用是显式的：调用方点名素材和字段，响应逐项报告成功和冲突。

### 详情与预览

选中一行会打开详情面板，包含元数据、数据集归属、校准证据、项目引用和文件位置。缩略图打开显示预览；FITS 素材提供 HDU 选择和文件头卡片。100 像素缩略图是索引图，显示预览是观看图，两者都永远不是科学输入。预览失败可以不改变素材可用性。

### 画布交接

把素材或数据集拖到画布上，会为该 id 创建数据源。数据集源在图运行时展开为有序成员路径，而不是在拖放时展开。拖放不复制文件，也不创建第二次登记；它记录图已经知道的 id。

### 变更检测

本地写入立即刷新受影响的行。外部变化通过轮询素材库变更令牌发现，而不是 websocket 或事件总线。素材、数据集、成员关系、校准绑定或回收站条目变化时令牌改变；看到新令牌的客户端重新获取当前页和打开的详情。

## Alternatives considered

**素材和数据集分成两个页面。** 否决：用户搜索的是一个素材库，不是两个数据库。分开会重复筛选、分页、计数和校准聚合，而且混合结果无法按拍摄时间排序。

**在浏览器里筛选和排序。** 否决：完整素材库放不进内存，观察到的筛选范围也必须与行来自同一个快照。服务端筛选还能让 CLI 和 MCP 的行为与网页一致。

**通过 websocket 或事件总线推送变化。** 首版否决：它会给单用户本地应用增加连接生命周期、重连和多客户端顺序问题。在有真正的实时协作需求之前，变更令牌轮询足够了。

**用最后写入者获胜的方式编辑。** 否决：两个打开的面板是常态，悄悄覆盖校准状态或曝光，比返回冲突更糟。修订检查与数据集和回收站修改使用的是同一套。

**把缩略图当作科学预览。** 否决：100 像素 JPEG 已经丢失了数据。科学读取走素材路径和输入模式检查，永远不走预览缓存。

## Acceptance criteria

- 素材库在一页里返回混合的素材行和数据集行，顺序稳定且显式，并带总数。
- 每个筛选都在分页之前应用，筛选选项反映当前素材库观察到的值。
- 数据集行聚合成员数、累计曝光和统一或混合的校准状态，而不加载每个成员。
- 过期的行内编辑返回 `409 REVISION_CONFLICT`，并保留更新的值。
- 手动编辑把该字段的值来源记为 `manual`，不会被之后的设备刷新覆盖。
- 缩略图或显示预览失败不改变素材可用性，也不阻塞数据集。
- 把数据集拖到画布会记录数据集 id，只在图运行时展开成员。
- 素材、数据集、成员关系、校准或回收站修改后，变更令牌会改变。

## Risks

- 带校准聚合和数值筛选的混合行查询是素材库最复杂的读取；它需要覆盖索引和真实行数下的查询计划测试。
- 变更令牌可能太粗，为了一行编辑刷新一大页；它应该是廉价的版本号，而不是结果集的完整 ETag。
- 行内编辑很多字段会放大修订冲突；UI 必须在提供重新加载的同时保留用户草稿。
- 前端 fork 已冻结；表格、筛选面板和详情面板必须适配现有扩展点，而不是修改上游组件。
