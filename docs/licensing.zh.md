# 许可证

[English](licensing.md) | 中文

本仓库以 **GPL-3.0-only** 发布。每个组件都带同一许可证，包括本可以另选的 MCP 服务器——它作为独立进程运行、不含引擎代码。全仓一个许可证省掉了逐目录判断。

| 组件 | SPDX | 依据 |
|---|---|---|
| 工作台服务 | `GPL-3.0-only` | 我们自己的代码，与派生的引擎一起分发 |
| MCP 服务器 | `GPL-3.0-only` | 独立进程；为省事取同一许可证 |
| 引擎 fork | `GPL-3.0-only` | 派生自 ComfyUI |
| UI fork | `GPL-3.0-only` | 派生自 ComfyUI_frontend |
| 引擎壳 | `GPL-3.0-only` | 运行在引擎进程内 |

## 发布必须携带什么

一个发布 tag 对应一个 commit，其树必须包含发布产物构建时所用的确切源码——引擎 fork、UI fork 与工作台——因为接收方有权索取他所收到版本的源码。第三方依赖保留各自的许可证，`LICENSE` 不替代它们。
